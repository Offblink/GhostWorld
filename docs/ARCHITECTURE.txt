═══════════════════════════════════════════════════════════════════════════════
  数据流
═══════════════════════════════════════════════════════════════════════════════

  外部 Agent ──→ ghostworld-send ──→ channel_server ──→ cmd_queue
  帧循环(每 tick) ──→ drain_agent_queue() ──→ process_agent_command ──→ handle_message ──→ WorldState
  执行结果 ──→ PendingCommand ──→ 连接线程 ──→ ack（一次工具调用里拿到）
  player WASD/chat ──→ local_client ──→ handle_message ──→ WorldState
  player 发言 ──→ handle_message(say) ──→ EventBus.publish(heard, kind=wake) ──→ ghostworld-wait
  任意事件 ──→ EventBus ──→ FileSink ──→ agent_output.jsonl（兼容层，每行带 seq）
  _tick_world (每 6 帧) ──→ 拾取/传送门/goto ──→ WorldState
  _build_snapshot() ──→ snapshot dict ──→ _apply_snapshot() ──→ entities[]
  entities[] + grid + colors ──→ render() ──→ pygame Surface

  地图切换: av.current_map 变化 → 深拷贝保存旧地图 items →
           加载新地图 grid/items/colors → 渲染新地图

  跨图传送: 进入传送门 → _resolve_portal_target 解析坐标 →
           越界校验 → av.x/y 设置 + current_map 切换

═══════════════════════════════════════════════════════════════════════════════
  命令通道
═══════════════════════════════════════════════════════════════════════════════

  外部 Agent ──→ ghostworld-send '{"cmd":...}' ──→ channel_server ──→ cmd_queue
                                   帧循环 drain ──→ handle_message ──→ ack 原路返回
  外部 Agent ──→ ghostworld-wait（阻塞在 127.0.0.1 socket 上；零轮询）
  玩家发言     ──→ EventBus.publish(kind=wake) ──→ 立刻推给正在等的那条连接
  其余事件     ──→ kind=observation（可订阅，不唤醒）

  发现文件: metaverse/.channel.json（port/token/pid；进程退出即删）
  游标文件: metaverse/.wait_cursor.json（按事件 seq；换了游戏进程 token 变了就归零）
  协议规范: docs/PROTOCOL-agent-channel.md
  退出码:   send 0/1/2 · wait 0/2/3

  旧文件通道（兼容层，仍在）:
    终端/AI ──→ agent_commands.jsonl ──→ agent 每 0.3s 读一次（先 move 再读）──→ cmd_queue
    EventBus ──→ agent_output.jsonl ──→ 终端/AI（listen.py 按 seq 跟读）
